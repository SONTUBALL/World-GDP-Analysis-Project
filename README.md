# World-GDP-Analysis-Project
A complete data analytics project focused on analyzing World GDP data using Python, SQL, Excel, and Power BI.

## Project Overview
This project analyzes World GDP data to identify economic trends, country-wise growth patterns, and regional performance using data analytics and visualization techniques.

### The project demonstrates:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Dashboard Creation
- Business Insights
  
## Tools & Technologies
- Excel
- SQL
- Python
- Power BI
